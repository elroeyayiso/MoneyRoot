# MoneyRoot v2
A functional personal finance dashboard.

Features:
- Add, edit, and delete transactions
- Income and expense tracking
- Personal dashboard calculations
- Category spending charts
- Add/edit/delete budgets
- Add/edit/delete savings goals
- Add/edit/delete debts
- Analytics generated from entered data
- Browser localStorage persistence
- Dark mode

Open index.html in a browser. No server is required for the local version.
